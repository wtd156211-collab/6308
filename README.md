# 图表标注避让（从 0 实现）

起始环境只有这份说明、`samples/**` 与 `.gitignore`，没有实现代码，程序要新写。Python 3.13、只用标准库，不加依赖与构建步骤；页面用原生 HTML/内联 SVG；自测用 unittest，只读 `samples/**`。

## 一、范围

在仓库根写单文件程序 `labels.py`（库与命令行入口合一）：给一批锚点与标签，按下面写死的口径算出每个标签放哪儿、哪些省掉。

    python3 labels.py place <图表.json> <结果.json>
    python3 labels.py page  <图表.json> <页面.html>

`place` 把结果写进 JSON，同时把规范清单打到标准输出；页面按 `web/index.html` 交付（用 01 号样例生成）。参数不对、文件打不开、JSON 不合法时，向 stderr 打一行 `error:` 开头的说明，退出码 2、不写产物；正常退出码 0。

明确不做的事：

- 不做坐标轴、图例、网格、提示框与数据曲线，只在一张二维画布上摆点状锚点与矩形标签；
- 标签不分行、不旋转、不缩放，固定一行、固定字号；不做锚点的自动布局、去重、聚类与交互；
- 不做批量并发与增量更新；不引第三方库与外部资源（CDN、字体、图片、网络请求），不写构建脚本。

## 二、口径与公式

### 2.1 坐标系与标签尺寸

- 画布是 W×H 的整数像素矩形，原点在左上角，x 向右、y 向下；锚点在画布内。
- 标签矩形固定高 h = 20；宽 w = 8 + 各字符宽度之和：码点 < 0x2E80 记 7（半角），其余记 14（全角），左右各留 4 内边距。
- 矩形记作 (x, y, w, h)，x、y 是左上角，右边界 x+w、下边界 y+h；全程整数运算，⌊·⌋ 向下取整。

### 2.2 候选位置（顺序写死）

锚点记 (ax, ay)。近位 8 个，按序号依次试：

    1 E (ax+8, ay−10)      2 W (ax−8−w, ay−10)
    3 N (ax−⌊w/2⌋, ay−28)  4 S (ax−⌊w/2⌋, ay+8)
    5 NE (ax+8, ay−28)     6 NW (ax−8−w, ay−28)
    7 SE (ax+8, ay+8)      8 SW (ax−8−w, ay+8)

近位全不行才试远位 12 个：长度 ℓ 按 20、32、44 由短到长，每档里按 E、W、N、S 试，引导线自动带上：

    E@ℓ (ax+ℓ, ay−10)         引导线 (ax,ay)→(ax+ℓ,ay)
    W@ℓ (ax−ℓ−w, ay−10)       引导线 (ax,ay)→(ax−ℓ,ay)
    N@ℓ (ax−⌊w/2⌋, ay−ℓ−20)   引导线 (ax,ay)→(ax,ay−ℓ)
    S@ℓ (ax−⌊w/2⌋, ay+ℓ)      引导线 (ax,ay)→(ax,ay+ℓ)

引导线长度就是 ℓ，上限 48；样例保证每个 `must_show` 都至少有一个可用候选。

### 2.3 候选的可用条件

四条都成立才可用；判定对象只含**已经放下**的标注，候选自己不算：

1. 矩形完整落在画布内：0 ≤ x、0 ≤ y、x+w ≤ W、y+h ≤ H；
2. 与每个已放下的标签矩形都满足最小间距 6：水平净距 dx = max(A.x−(B.x+B.w), B.x−(A.x+A.w))（垂直同理），dx ≥ 6 或 dy ≥ 6 才算过；
3. 矩形与任何已放下的引导线没有公共点（压边也算）；
4. 远位的引导线与任何已放下的标签矩形、任何已放下的引导线都没有公共点。

### 2.4 处理顺序与省略

- 按 (must_show 优先, priority 小, 输入顺序) 排处理顺序；`must_show` 缺省 false，`priority` 取 1..9。
- 每个标注依次试 20 个候选取第一个可用的，近位全不行才轮到远位；放下就不再移动，不回退、不交换、不重排。
- 20 个都不行时：非 `must_show` 记入省略清单，不占位、不画线；`must_show` 记进「必须显示未放下」（样例不会出现，页面要如实报出来）。

## 三、数据结构与流程

读入图表 → 按 2.4 排序 → 依序找每个标注的第一个可用候选 → 写结果；状态只有三样：已放下的标签矩形、已放下的引导线、省略清单。

`placed` 每条记 `id`、`x`、`y`、`w`、`h`、`leader`（近位为 `null`，远位是 `[x1, y1, x2, y2]`），`omitted` 与 `must_show_omitted` 只记 `id`；两个清单按**输入顺序**排，顺序敏感。

## 四、输入输出与文件格式

一律 UTF-8、LF、末行有换行；数字都是十进制整数。

### 4.1 图表 `samples/charts/*.json`

    {"canvas": {"width": 640, "height": 360},
     "labels": [{"id": "d01", "text": "川渝", "anchor": [279, 166], "priority": 1, "must_show": true}, …]}

`labels` 的先后就是输入顺序；`id` 唯一；`text` 非空；`anchor` 在画布内；`must_show` 可省。

### 4.2 结果 JSON

    {"placed": [{"id": "m01", "x": 331, "y": 195, "w": 36, "h": 20, "leader": null}],
     "omitted": ["d04"], "must_show_omitted": []}

### 4.3 规范清单

`place` 打到标准输出，页面里的 `<pre id="summary">` 与它逐行相同：

    place <id> <x> <y> <w> <h>
    lead  <id> <x> <y> <w> <h> <x1> <y1> <x2> <y2>
    omit  <id>
    miss  <id>

先按输入顺序列放下的（近位 `place`、远位 `lead`），再按输入顺序列 `omit`，最后列 `miss`（样例为空）；单空格分隔、行尾无空格。`samples/expected/*.txt` 与图表同名，内容就是这份清单，逐行核对、顺序敏感。

### 4.4 页面

单文件、双击可开、不引外部资源、不 fetch、不依赖脚本执行：

- 顶部 `id="verdict"` 的元素里带 `省略 <k> 个` 与 `必须显示未放下 <j> 个`（k、j 取自结果）；`<pre id="summary">` 即 4.3 的规范清单；
- 内联 `<svg id="chart" viewBox="0 0 W H">`：每个标注一个 `<circle class="anchor" data-id>`，放下的实心（`r="3"`），省略的空心（`fill="none"`、`r="4"`、`data-omitted="1"`）；
- 每个放下的标注一个 `<rect class="label" data-id x y width height>`（几何与结果一致）与 `<text class="label-text">`（就是标签文本，x 取矩形左边 + 4、y 取上边 + 15）；远位放下的另加 `<line class="leader" data-id x1 y1 x2 y2>`，与结果一致。

页面上的数字与几何只能来自实现输出，不重算、不带时间戳。

## 五、性能与验收口径

预算（Python 3.13、单线程、冷启动计入）：单个图表（含 05 号那 2892 个标注）跑 `place` 或 `page` 不超过 5 秒，峰值内存不超过 256 MiB；五组样例合计不超过 20 秒。

判定：

1. 逐组 `python3 labels.py place samples/charts/<名>.json var/<名>.json`，退出码 0，标准输出与 `samples/expected/<名>.txt` 逐行一致；
2. 逐组跑 `page`，退出码 0；`<pre id="summary">` 与期望逐行一致，`verdict` 的 k、j 与结果一致，`rect`、`line` 几何与结果一致，省略的锚点是空心点，页面无外部引用；
3. 复核不变量：矩形都在画布内、两两净距满足 6、不压已放下的引导线、引导线互不相交且不超过 48、位置都在 2.2 的候选表里、处理顺序符合 2.4；
4. 确定性：同一输入连跑两遍、并换 `PYTHONHASHSEED=0/1/2`，标准输出与产物逐字节相同，`must_show_omitted` 为空；
5. 不许写死：不得读 `samples/expected/**` 参与计算，不得按样例名、标注数或坐标特判；验收会换图表。

## 六、样例说明

- `01-dense-cluster`：18 个短标签挤在 142×92 的簇里，11 个放下（5 条引导线）、7 个省略；
- `02-long-labels`：14 条 9~12 字的长标签铺满画布，12 个放下（4 条引导线）、2 个省略；
- `03-edge-hugging`：12 个锚点贴着四条边，近位大量被画布挡掉，9 个放下、3 个省略；
- `04-mustshow-close`：5 个必须显示的标签挤在 24×18 里，全部放下、其中 3 个靠引导线；
- `05-low-priority-swarm`：2880 个低优先级标签散在 12 个簇里，另 12 个必须显示，360 个放下、其余省略。

每个 `<名>.json` 对应同名 `expected/<名>.txt`；`samples/notes.md` 是现场记录。
